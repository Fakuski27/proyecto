# Portfolio Responsive

Proyecto realizado para la práctica de Maquetación Avanzada de Grilla y Responsividad.

## Requisitos aplicados

- Mobile First.
- CSS Grid.
- `grid-template-areas`.
- `grid-template-columns` con unidades `fr`.
- `gap` en Grid y Flexbox.
- Flexbox para navegación, botones y otros componentes.
- Breakpoint desktop obligatorio: `@media (min-width: 1024px)`.
- Diseño responsive para mobile, tablet y desktop.
- Dos páginas funcionales:
  - `index.html`
  - `pages/proyectos.html`

## Estructura

```text
proyecto-responsive/
├── index.html
├── css/
│   └── style.css
├── pages/
│   └── proyectos.html
└── README.md
```

## Cómo probar

Abrir `index.html` en el navegador. También se recomienda utilizar Live Server desde VS Code.
